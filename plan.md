# Чисто памятка для себя, примерный план работы

## Общее описание

По приоритетности:

1. **В общем, я хочу создать ии приложение, которое будет принимать на вход музыку, возвращать ноты, гитарные табы и/или аккорды (*сюда бы ещё бой*).**

2. И ещё одно, пока потенциальное, направление развития - подготовка аудио к игре, т.е. убирать партию выбранного пользователем инструмента, для создания идеального минуса для игры. 

3. И третья функция, совсем на заднем плане - распознавание музыки, т.е. фактически шазам.

4. В идеале, чтобы у пользователя была возможность менять тональность готовых нот прямо в приложении. Либо даже своего аудио

5. Ну и совсем уж чтоб по красоте, можно впихнуть ещё и тюнер.

6. А раз уж есть распознавание нот, то не помешало бы добавить распознавание текста. Вокальная партия - тоже партия. К тому же для аккордов то, что надо.

7. Основы муз теории, что-то вроде вкладки учебник

Фактически, основная идея здесь только первый пункт, дальше уже возможности развития

### Input
Также я бы хотела отдельно уделить особое внимание подаче аудио на вход. Здесь также я бы хотела рассмотреть все варианты:

*Основной в первичной версии:*
- просто выгрузка файла с устройства

*Особо желаемый*:
- виджет как у шазама, чтобы можно было просто проиграть отрывок на том же устройстве

*Потенциальное развитие:*
- ссылка на какого-нибудь партнёра (в потенциале) - а-ля яндекс музыка, VK музыка, спотифай, саундклауд и тд
- внутренний поиск по названию 

### Output
На выходе, в первую очередь должны быть ноты/табы/аккорды и/или текст. Касаемо **формата**, я думаю, что это должен быть:
- файл(pdf, jpeg, png и тд, на выбор пользователя)
- какая-то веб версия, чтоб можно было всё делать прямо внутри сервиса

Если дальше следовать, то по *второму* пункту - готовое аудио, с убранной партией. По *третьему* - просто название мелодии и (по хорошему) возможность прослушать ее онлайн. Ну, то есть, опять же, просто встроенный шазам. По *четвёртому* снова либо ноты, либо аудио (уже чисто файлом). *Пятое* и пояснять не надо. *Шестое* по первому. А *седьмое*, думаю, в принципе, понятно.

Это чисто выполнение самой базы, используя python и библиотеки TensorFlow и Keras для работы с ии. Также знакомство с ML и попытка создать свою модель

#### В полноценных условиях 
Тут уже должно быть действительно большое кроссплатформенное приложение, с отдельно прописанными бэком и фронтом, а также явно более детальная ИИ модель.
